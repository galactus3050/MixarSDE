## Installation

Clone the repository:

```bash
git clone https://github.com/galactus3050/MixarSDE.git
cd MixarSDE
```

Install dependencies:

```bash
pip install -r requirements.txt
```

or build the project:

```bash
mkdir build
cd build
cmake ..
make
```

---

## Usage

Run the application:

```bash
python main.py
```

or

```bash
./build/mixarsde
```
